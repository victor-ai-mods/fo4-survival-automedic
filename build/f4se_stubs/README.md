# build/f4se_stubs

Заглушка для компиляции: мод зовёт F4SE-функцию `ObjectReference.GetInventoryItems()`
(один вызов вместо перебора ячеек инвентаря), а исходников F4SE в игре нет — только `.pex`.
Компилятору нужен `.psc`, в котором эта функция объявлена.

Самого файла в репозитории нет: это ванильный исходник Bethesda. Создайте его сами, один раз:

1. Скопируйте сюда `<игра>\Data\Scripts\Source\Base\ObjectReference.psc`
   (в некоторых сборках он лежит в архиве `Fallout4 - Misc.ba2`, распаковать можно
   `tools/ba2.py` или любым распаковщиком BA2).
2. Допишите в конец файла, перед `EndState`-блоками не нужно, просто последней строкой:

   ```papyrus
   Form[] Function GetInventoryItems() native
   ```

`build/compile.ppj` импортирует эту папку первой, поэтому компилятор берёт именно её копию
`ObjectReference`. Комментарий внутри `<Imports>` компилятор не принимает.

Оригиналы объявлений F4SE — github.com/ianpatt/f4se.
