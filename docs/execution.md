## Режимы нажатия (`AM_TestMode`, консоль)

| Значение | Что делает нажатие |
|---|---|
| `0` (по умолчанию) | полный цикл с приёмом |
| `1` | тест A16 шага 4 |
| `2` | план без приёма (dry-run, как на шагах 3–5) |

Константа `DRY_RUN` убрана: dry-run теперь переключается на лету (`set AM_TestMode to 2`).

## Порядок

| Фаза | Что | Как |
|---|---|---|
| 1 | стимпак на конечности | строка плана |
| 2 | вывод радиации (кроме еды) | строки плана |
| — | пауза `SETTLE_WAIT` 1 с, если что-то принято | голод от RadAway и жажду от стимпака `HC_Manager` засчитывает асинхронно |
| 3 | голод | **цикл**: самое дешёвое → `EquipItem` → ждать смены `HC_HungerEffect` (до 1.5 с) → повторить |
| 4 | жажда | то же по `HC_ThirstEffect` |
| 5а | рад-еда | строки плана; только сытым (M4) |
| 5б | ОЗ | строки плана, **нужда перечитывается** (`RECHECK`) |
| 6 | болезни, зависимости | строки плана; еда-лекарство (омлет) — только сытым |

Применение — только `EquipItem(item, false, true)` (A16). Штука засчитывается, когда её счётчик
упал (ждём до 2 с); не упал — строка в `SKIP` и `UNMET`.

## Решения

- **Циклы смотрят на живую стадию**, а не на нужду фазы 0: голод, который принёс RadAway фазы 2,
  цикл тоже закроет. Поэтому при нужде в выводе радиации еда ищется в инвентаре, даже если игрок
  сыт, а при нужде в ОЗ или конечностях — питьё (`BuildNeeds`). На план это не влияет.
- **«Стадия не сдвинулась» — норма, а не приговор предмету.** Стадия — целое, насыщение копится в
  скрытом пуле `HC_Manager` и меняет стадию только на порогах. Цикл берёт одно и то же самое дешёвое,
  пока стадия не дойдёт до цели; встаёт, если `MAX_STALLED` = 7 штук подряд её не сдвинули (значит,
  не насыщают), или на `MAX_ITEMS_PER_NEED` = 12. Первая версия исключала такой предмет — см. прогон ниже.
- **Цикл сначала берёт штуки, которые плану не нужны.** Вопрос, открытый на шаге 5 (G6): план на ОЗ
  рассчитывал на 3 пищевые пасты, а цикл голода съел бы их голодным (M4). Теперь паста уйдёт в цикл,
  только когда кончится вся остальная еда; тогда строка плана не найдёт её в инвентаре → `SKIP`.
- **Цена в цикле** (`LoopCost`): крышки + 5 за 1 % риска (×2 при немедленной проверке) + радиация
  в ОЗ потолка (M1). Правила по радиации те же, что у плана (`MAX_INGESTED_RADS`, решение 1),
  с учётом съеденного циклами.
- **Фаза 5 — обрезка по факту.** План считался до циклов, а с тех пор стимпак фазы 1 уже капает, вода
  из цикла жажды подлечила (A3), рад-еда тоже. `RecheckHP` берёт живые ОЗ и радиацию, остаток
  «в полёте» (`ScanInFlight` — лёгкий `GetActiveEffects` без статусов) и радиацию ещё не исполненных
  строк; строка на ОЗ, без которой нужда уже в допуске, пропускается.
- **Занятость.** Исполнение с циклами длится десятки секунд; каждое `Consume` продлевает
  `AM_BusyStart`, так что `BUSY_TIMEOUT` (60 с) считается от последнего приёма.
- **`Utility.WaitMenuMode`**, а не `Wait`: нажатие из Pip-Boy не ждёт закрытия меню.

## Лог

```
  USE    1. Stimpak -> limbs+hp  [+416 HP]
  USE    2. RadAway -> rads  [-880 rad]
  USE    3. Tato -> hunger 2 -> 1 (Peckish)  через 212 мс
  USE    4. Tato -> hunger 1 -> 1 (Peckish)
  USE    5. Tato -> hunger 1 -> 0 (Fed)  через 180 мс
  RECHECK hp 210, в полёте +416, потолок 473 -> нужда 0 (план ждал 180)
  SKIP   Grilled Radroach [hp]: уже не нужен (нужда 0 <= допуск 9)
  AFTER  HP 210/473 (+416 в полёте), Rads 20 (-500 в полёте), Fed, Hydrated
  SPENT  -1 Stimpak, -1 RadAway, -3 Tato  (...)
  UNMET  none
```

Экран: `AutoMedic: -1 Stimpak, -1 RadAway, -3 Tato | HP 210/473 (+416 в полёте), …`.
В `TIME` добавлено `исполнение N мс`.

## Проверка в игре

**Готово, когда** (§9): цикл по голоду сходится за ≤ 3 предмета из Hungry до Fed и
останавливается на предмете, не дающем насыщения.

Оговорка к «≤ 3»: недостижимо ни в ванили (M3: 4–8 дешёвых), ни под SCM этой сборки (любая еда +8,
Hungry — пул −48…−96, то есть 6–12 штук; прогон ниже). Фактический критерий: цикл доводит до Fed
самой дешёвой едой без перебора и встаёт, когда предметы не насыщают.

Сейв в Survival, который не жалко. Набор предметов:

```
player.additem 23736 5      ; Stimpak
player.additem 23742 3      ; RadAway
player.additem 366C0 4      ; Purified Water
player.additem 21188E 2     ; Mutant Hound Chops
player.additem 19797D 2     ; Grilled Radroach
player.additem 8AB 1        ; Antibiotics
```

⚠️ **Урон — только от текущих ОЗ, не фиксированным числом.** Радиация срезает максимум (M1): после
E5 (`damageav rads 400`, 529 rad) у персонажа было 224/224 ОЗ, и следующий `damageav health 300`
его убил (прогон 22:35). Перед тестами на ОЗ — `player.restoreav rads 1000` и `player.getav health`,
урон = ОЗ − 80.

⚠️ `player.setav HC_HungerEffect 2` меняет только стадию, а скрытый пул остаётся «сытым»:
первый же предмет вернёт Fed. Для E1 нужен **настоящий голод** — сесть на стул и подождать
12–24 часа (в Survival ждать можно только сидя), пока Pip-Boy не покажет Hungry.

**Главное (по `Hardcore.1.log`): под SCM каждый предмет даёт ровно пол стадии** — еда +8, вода +18,
