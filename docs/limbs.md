# Флаг `limbs` в items-user.json (2026-11-20)

Повод: вопрос cmdgz123 на Nexus (комментарий 180144723) — в его сборке стимпак конечности не лечит,
нужны бинты из другого мода, а AutoMedic их не знает. Коммит `96fd2a2`, разложено 2026-11-20 00:16.

**Проверено в игре 2026-11-20 00:24–00:27** (стенд Dev, профиль MO2 «AutoMedic Test», сейв главной
игры Quicksave0 от 2026-11-11, авторежим Виктора вкл., резерв стимпаков 20, стимпаков 186):
строка `+ Fallout4.esm|0366C0: … лечит конечности`, ошибок 0; цикл #1428 `limbs 2` кандидата
(стимпак + вода) → `limbs <- Очищенная вода`, выпита; #1430–#1432 `limbs item True` → «предмет для
конечностей уже действует», ничего не потрачено; #1433 эффект кончился (`limbs item False`) →
снова вода. Предпочтение перед стимпаком здесь совпало с ценой (вода 32 против 53) — отдельно
его проверяет plan_sim L1.

Как работает — README.ru.md, §5 стадия B и §10a. Коротко: предмет с флагом `limbs` идёт на
конечности раньше стимпака, даже при стимпаке в полёте; пока его эффект идёт (`S_LimbItemActive`,
по `MagicItem` в GetActiveEffects), второй не берётся. Резерв стимпаков и `CombatRateStimpak` —
только стимпаки (`K_Stim`). Бит — бывший `FLAG_POISON` (0x4), ядов в таблице нет.
Офлайн: plan_sim L1–L5.

## Минимальная проверка в игре

Бинта под рукой нет, его играет очищенная вода (лечит 40 ОЗ за 100 с в Survival — эффект
идёт долго, удобно для проверки «уже действует»).

1. `Data\SurvivalAutoMedic\items-user.json`:
   ```json
   {
       "items": [
           "Fallout4.esm|0366C0|heal=40|sec=10|limbs"
       ]
   }
   ```
2. Полный перезапуск игры, загрузка. В инвентаре стимпаки и очищенная вода. Лог — «Подробно».
3. Консоль: `player.damageav leftmobilitycondition 100` (левая нога покалечена).
4. Нажать AutoMedic. Ждём в логе: строка своих предметов `+ Fallout4.esm|0366C0: … лечит конечности`,
   `PLAN limbs <- Очищенная вода` (не стимпак).
5. Сразу нажать ещё раз. Ждём: `limbs: предмет для конечностей уже действует, второй не нужен`,
   в STATE `limbs item True`.
6. Убрать items-user.json, MCM «Предметы» → «Перечитать свои предметы», вылечить ногу стимпаком.

## Полевой список (по ходу игры)

- Настоящий мод с бинтами: лечит ли один бинт все конечности (наша модель) или по одной.
- Бинт мгновенный (без длительности): следующий цикл не берёт второй, если нога уже цела.
- Стимпак в полёте + бинт: бинт берётся сразу (L2).
- Бинтов нет: как раньше, стимпак; резерв стимпаков бинты не трогает (L4).
